# 📞 Contact App – Android Application

Contact App is an Android application developed using **Kotlin** and **Jetpack Compose**.  
This app allows users to manage contacts efficiently by providing features such as adding, deleting, and directly calling contacts.  
The project follows **MVVM Architecture** to maintain clean code and proper separation of concerns.

---

## 🚀 Features
- ➕ Add new contacts
- 🗑️ Delete existing contacts
- 📞 Direct phone calling functionality
- 🧭 Navigation between different screens
- 🎨 Modern and responsive UI using Jetpack Compose
- 🧩 Clean and structured code using MVVM Architecture

---

## 🧱 Architecture (MVVM)
The application is built using the **MVVM (Model–View–ViewModel)** architecture pattern:

- **Model:** Manages data using Room Database
- **View:** UI layer built with Jetpack Compose
- **ViewModel:** Handles business logic and UI state

This architecture improves **maintainability, scalability, and testability** of the application.

---

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Architecture:** MVVM
- **Database:** Room Database
- **Navigation:** Navigation Component
- **IDE:** Android Studio
- **Build System:** Gradle

---

## 📂 Project Structure
- `data/` – Room entities, DAO, and database classes  
- `ui/` – Jetpack Compose screens and UI components  
- `viewmodel/` – ViewModel classes  
- `navigation/` – Navigation Component setup  
- `MainActivity.kt` – Application entry point  

---

## 📞 Calling Feature
The app supports **direct phone calling** functionality using Android call intent.  
Proper permissions are handled to allow users to make calls directly from the app.

> Note: Calling feature works on a **real Android device**.
